# gt-traditions
Digital Story about GT school spirit.

## What’s All the Buzz at GT?

A student digital story about the Ramblin’ Wreck, Buzz, and the crowd at Bobby Dodd Stadium.

Preview the site from the repository root with `python3 -m http.server 8000` and open `http://localhost:8000`.

Edit the chapter and bibliography content in `fragments/`. Run `python3 build.py` to regenerate the HTML pages before committing. The site uses static files that GitHub Pages can serve from the repository root.
